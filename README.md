# Webpkit

WebP encoding and decoding in Rust.

## Installation

```sh
git clone https://github.com/P4suta/webpkit.git
cd webpkit
cargo install --path crates/webpkit-cli --locked
```

## Usage

```sh
webp photo.png
```
